# Vox视觉系统与风格锚点

## Vox的工作定义

把Vox定义为解释型编辑视觉系统：通过摄影、地图、文字、图形、信息结构、材质和运动，让复杂观点快速可理解。不要把它缩减为白底、纸片或某一种配色。

## 初始视觉分支

这些是内部候选，不是官方分类，可在样片验证后增删：

1. 纸媒拼贴：撕纸、摄影剪贴、黑白半调、彩色纸块、印刷颗粒。
2. 现代编辑混合：摄影、排版、地图、数据、几何关系与编辑留白。
3. 摄影图形融合：真人/真实场景承担可信度，图形与文字承担解释。
4. 受控3D编辑：仅在空间、层级或结构需要时使用3D，并继承同一字体、色彩关系和编辑层级。
5. 原片底片叠层：原片动态视频保持全屏或主画布，上层用纸媒、照片、路径、标签、MG 和强调组件解释语义；组件可与人物和场景发生遮挡、穿插和接力，但不能遮脸或关键动作。原片烧录字幕允许自然保留，不为消除它破坏构图。

## 锚点锁定项

- 字体家族、字重和信息层级；
- 照片是原色、双色调、半调还是剪贴；
- 纸张、印刷、噪点、描边、阴影和边缘；
- 信息密度与空间张力；
- 主次关系、留白和组件分组；
- 动作是组装、绘制、筛选、替换、展开还是对照。

## 锚点非锁定项

- 不锁死每帧背景颜色；
- 不锁死每帧版式；
- 不锁死组件数量；
- 不强迫真人每段出现；
- 不让所有页面看起来像同一张模板。

颜色要形成语法而不是固定值。例如一条片可以使用青绿、橙、米白、黄和黑白，但需保持相似的纸张、字体、照片处理、阴影和强调关系。

## 组件不是风格

地图、Dashboard、信息卡、列表、关系网、进度条、路径和时间线只是解释工具。使用前先回答它解释当前语义中的哪个关系，再把它重新设计成锚点语言。不匹配就不用。

## 高信息密度

允许一帧有很多独立物件。控制的是信息组和竞争中心，而不是纸片数量。一个高密度画面仍应只有一条主要推导路径和一个最终结论。
