# 反复问题防错闸门

每次制作开始前，把本文件当作硬性检查单；任一项失败，先局部返工并重新抽关键帧，不得直接完整渲染。

## 画面与真人

- 先确认输出画幅和原片比例，再决定 `contain`、自然裁切或圆形/矩形动态窗口。允许匹配构图的自然裁切，但不得把人物硬切成半截、切断关键动作，或让裁切后下方出现无意义空洞；窗口边界、人物重心和留白必须一起成立。
- 真人画面必须来自原片动态视频/动态抠像；每帧最多一个真人实例，但呈现形式不得固定。应根据语义、构图和层级在自然抠像、圆形窗口、圆角矩形窗口、局部出场、短暂隐藏等方式之间选择；“卡片”只是用户明确需要时才可采用，禁止把卡片当默认模板。
- 原片或人物窗口中已经烧录的字幕允许自然保留，也不作为构图否决项。不得为了消除烧录字幕而强行放大、裁切、遮罩、移动人物或牺牲画面层次；以脸、关键动作、主视觉关系和整体构图成立为先。只有用户明确要求清除烧录字幕时才单独处理。
- 侧边辅助必须服从整帧判断：先确定视觉中心、字幕空间和信息密度，再选择语义图像、照片、贴图、纸媒拼贴、MG 图形、短标签或留白；不能机械规定每帧都要放侧边元素。唯一硬禁令是不得把侧边做成第二套口播字幕或长段转写文字，必要标签只能承担识别和关系提示。
- 画面要有主视觉中心和从属层级，但不能退化成固定卡片、资料卡、色块加箭头的模板，也不能用左右对称符号填空。每个语义段至少更换一种主物件、空间关系或运动机制；人物窗口形式也要按画面需要变化，不能整条片固定一种。

## 字幕与时间

- 读取 SRT 的最后一个 cue 和原视频时长，建立完整覆盖表；不得只规划前 9 秒或按固定 3 秒切段后遗漏尾段。
- 时间码是唯一执行主轴；每个动画、进度节点、音效点都写明“口播词—起止时间—开始/落定帧”。禁止整段匀速进度。
- 默认一画面一句、一行；只有同一句无法自然保持单行且拆开会破坏句意时，才允许同一 cue 两行。禁止两句不同字幕同时出现。
- 关键帧必须覆盖开头钩子、每个语义转折、结论/CTA 和最后一帧；不能只给开头示例就宣布完成。

## 参考与版本

- 成片默认不得添加 Skill 名称、工具名、模型名、内部项目名、VOX/Remotion 标识或任何未获用户授权的品牌水印；右上角、左上角和底部角落都要检查。只有用户明确要求时，才允许加入指定品牌标识。
- 用户给的示例只在用户明确授权时继承版式；未授权时仅提取质感、层次或技术机制，必须换构图、物件和运动路径，避免沿用上一个成片。
- 生成新版本前先列出与上一版本的差异：主物件、构图、色彩、人物位置、动效机制至少改变两项；若用户要求延续，记录为 `reference_scope=system_anchor`。
- 每次返工保留原片、SRT、审核脚本、执行大纲和已通过关键帧；只替换失败语义段，不能用新模板覆盖全片。

## 渲染闸门

1. 分层清单：运行 `validate_layer_manifest.py`；缺少至少 3 个独立视觉层、MG 任务单或出现重复源假图层时立即阻断。
2. 静态关键帧：确认人物裁切自然且构图匹配、脸和关键动作未被破坏、侧边形式服务整帧、语义清楚；烧录字幕本身不作为否决项。
3. 语义节点关键帧：确认时间码覆盖全片、进度不抢跑、相邻段有新信息。
4. 2–5 秒动态样片：确认进入—构建—结论—接力连续，音效与动作同帧。
5. 全片渲染与 QC：确认原声、BGM、音效可独立关闭，且手机缩略观看仍可读。

## 共轴组件防错

- 出现两个以上指针、针臂或围绕共同中心运动的元素时，禁止把它们合并成一张图后整体旋转。
- 每个组件必须独立建层，但 `pivot` 必须完全相同；每个组件分别声明目标角度和落定帧。
- 自动检查最终方向是否重合或夹角过小；出现“都指向同一方向、轴心偏离中心、针尾围着中心漂移”时立即阻断渲染。
- 至少抽取起势、落点、稳定三帧核对；只看一张静帧不能证明联动正确。

任何一层未通过，都只能回到对应层处理；不得跳过闸门或以“已生成文件”代替验收。
