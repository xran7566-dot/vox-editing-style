# 公共素材来源（可选）

公共素材可来自用户已合法取得并明确提供的 Pixabay 等公共来源素材，可包括图片、短视频、纹理、物件、BGM 与音效。它不是主视觉引擎：Director 决定语义、构图和素材职责；公共素材只补充一个明确需要的真实素材层；Remotion 只合成已通过记录的素材。

## API 边界

Vox 不调用 Pexels API 或 Pixabay API，不申请、不保存、不索取 API Key，也不在任何脚本、环境变量、前端或记录文件中配置它们。用户提供的公共素材可按本合约记录和使用；若未来其他 Skill 需要使用这些 API，它必须独立实现、独立授权，不能成为 Vox 的隐式依赖。

## 何时调用

仅当 Director 的已批准执行大纲为某语义镜头提出具体的公共素材请求，且用户已提供或明确授权使用符合条件的公共素材时，才把该素材纳入项目。请求须使用 `assets/public-material-request-template.json`，明确时间码、素材职责、检索词、必须满足条件、禁忌和语义理由。

不因“画面还缺一层”而搜索，不按好不好看随意补图，也不在没有请求时读取、下载或复用上一项目素材。

## 检索结果

- **qualified**：素材与请求匹配、无禁忌、可用于新的组合画面。保存文件并生成 `public-asset-record.json`；只有此状态的素材可进入 `layer-manifest.json`。
- **not_found**：没有合格候选。取消该公共素材层；不得以近似、抽象或无关候选替代。
- **rejected**：候选存在但与语义、许可、人物/品牌风险或画面职责不符。记录原因后取消该层。

当公共素材层取消时，Director 已批准的生成视觉继续作为主视觉；Remotion 不得自行画一个“替代图形”。需要新的生成层时回到 Director 资产阶段，而不是由渲染阶段自由发挥。

## 来源记录与交付

每个入选文件都必须有同目录的 `public-asset-record.json`，至少记录来源页 URL、下载时间、素材类型、语义职责、使用时间码、原文件 SHA-256、许可核对和改编方式。使用 `scripts/validate_public_asset_record.py` 校验后才可写入分层清单。

素材必须参与剪辑、组合、动画或其他创作性改编；不能把原文件作为独立素材包重新分发。出现可识别人物、商标、品牌或敏感情境时，一律拒绝该候选。
