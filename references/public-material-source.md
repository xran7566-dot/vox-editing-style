# 公共素材来源（可选）

公共素材是 Vox 的可选补充层，不是主视觉引擎：Director 决定语义、构图和素材职责；公共素材只补充一个明确需要的真实素材层；Remotion 只合成已通过记录的素材。

## 当前入口与备用接口

保留两个可选网站来源：**Pexels 网站**补充图片、视频和空镜；**Pixabay 网站**补充图片、视频、音乐和音效。按本次已确认大纲的具体缺口检索，不自动批量检索，也不主导画面。

网站可访问不等于已安装自动检索插件。`pixabay_music` 若实际可用，只按其已验证的音乐能力使用；不能假定它也搜索图片/视频，更不能依赖其他用户未安装的 OpenMontage。没有可用网站工具时可按网页流程选材，访问被拒绝则记录缺口并跳过，不绕过限制。

Pexels API 与 Pixabay API 是未接通的备用接口，不读取 Key、不出现在当前素材请求中。只有某次具体任务确实需要程序化批量检索，且网站工具无法满足时，才先向用户说明：拟接通的 API、必要性、Key 的本机保存方式、额度和来源展示要求；获得本次明确确认后才能实现和调用。

记录中的 provider/selected_provider 按实际来源填写 `pexels_web` 或 `pixabay_web`；模板默认值不是固定选站要求。Pexels 记录必须填写 `creator`。

## 何时调用

仅当 Director 的已批准执行大纲为某语义镜头提出具体的公共素材请求时，才使用网站工具。请求须使用 `assets/public-material-request-template.json`，明确时间码、素材职责、检索词、必须满足条件、禁忌和语义理由。

不因“画面还缺一层”而搜索，不按好不好看随意补图，也不在没有请求时读取、下载或复用上一项目素材。

## 检索结果

- **qualified**：素材与请求匹配、无禁忌、可用于新的组合画面。保存文件并生成 `public-asset-record.json`；只有此状态的素材可进入 `layer-manifest.json`。
- **not_found**：没有合格候选。取消该公共素材层；不得以近似、抽象或无关候选替代。
- **rejected**：候选存在但与语义、许可、人物/品牌风险或画面职责不符。记录原因后取消该层。

当公共素材层取消时，Director 已批准的生成视觉继续作为主视觉；Remotion 不得自行画一个“替代图形”。需要新的生成层时回到 Director 资产阶段，而不是由渲染阶段自由发挥。

## 图片整理与分层

下载图片是素材获取，不是完成多图层制作，Remotion 不会自动把照片变成真正的分层资产。完整照片可以作为一个独立信息层；需要丰富画面时，让其他真实物件、文字、路径或 MG 组件承担不同语义职责，而非强抠照片、复制同图或硬凑三层。是否抠像取决于边缘、遮挡、光影和构图是否自然；不合适就保留完整图片或换素材。

每个项目独立整理 `assets/images/`、`assets/video/`、`assets/audio/` 与来源记录；原始文件不覆盖，处理后的版本另存并关联原始指纹。清单写明文件用途、原图/衍生图关系、使用镜头和审核状态。未审核、重复、无关素材不进渲染；不从上一项目自动借图。选择素材不是越多越好，单镜重点与全片层次共同判断。

## 来源记录与交付

每个入选文件都必须有同目录的 `public-asset-record.json`，至少记录来源页 URL、下载 URL、提供方、下载时间、素材类型、语义职责、使用时间码、原文件 SHA-256、许可核对和改编方式。Pexels 结果还须记录创作者和来源链接；素材审核页应展示该来源信息，但成片不添加 Skill 或工具水印。使用 `scripts/validate_public_asset_record.py` 校验后才可写入分层清单。

素材必须参与剪辑、组合、动画或其他创作性改编；不能把原文件作为独立素材包重新分发。出现可识别人物、商标、品牌或敏感情境时，一律拒绝该候选。
