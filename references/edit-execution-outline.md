# 剪辑执行大纲合约

## 定位

前面的 `VOX-CONTENT` 已完成内容拆解和结构判断。本文件只负责把已确认内容翻译为可执行的时间线、镜头、图层、动效、衔接和声音点位；不得重新改写口播或凭空增加事实。

## 时间基准

- **时间码是唯一主轴**：以原声/SRT 的 `start`、`end` 定义语义段和字幕时机。
- **镜头是执行单位**：每个镜头对应一个语义段或明确的语义变化。
- **帧数是技术落地**：按项目 fps 将时间码换算为帧，不能反过来用固定帧数切断口播。
- 每段必须记录 `timecode`、`shot_id`、`start_frame`、`end_frame`；动画事件再记录 `start_frame`、`settle_frame`、`hold` 和 `exit_frame`。

## 每段必填字段

| 字段 | 要回答的问题 |
|---|---|
| 时间码/帧范围 | 什么时候开始、结束，如何换算为帧？ |
| 原声/字幕 | 这一段实际说了什么？ |
| 表达含义 | 观众此刻应该理解什么？ |
| 镜头目的 | 这一镜承担钩子、解释、转折、证据还是结论？ |
| 基础画面模式 | 原片底片叠层、拼贴主画面加真人窗口、动态抠像融合，还是按镜头混合？ |
| 七层画面 | 背景、结构、信息、关系、真人、强调/退出、声音如何安排？ |
| 衔接方式 | 上一镜的什么元素接力到下一镜？ |
| 声音点位 | 哪句话/哪个动作触发什么 BGM 变化或音效？ |
| 返工条件 | 什么情况回退到视觉方案或局部修改？ |

## 七层画面规则

每镜按需规划：背景层、结构层、信息层、关系层、真人层、MG 动画层、强调/退出层、声音层。MG 动画是正式组成图层，负责路径生长、元素组装、连线、遮罩、空间层次和转场，不是后期装饰。允许多层错峰运动，但每镜只设一个视觉主动作，动画顺序为“进入 → 建立关系 → 强调 → 停留 → 退出”。真人是叙述锚点，可全屏、圆形、矩形、拼贴式动态出现或暂不出现，不固定在左右卡片。

### 基础画面模式

- `source_video_base_overlay`：原片动态视频铺满竖屏或主画布，保留原动作和环境；其上至少叠加 3 个彼此独立、按语义进出的 Vox/MG 组件。原片可计为背景层，但不计入 3 个上层组件。
- `collage_main_with_presenter`：拼贴承担主要视觉解释，真人以动态窗口、圆形/矩形或局部出场保留人设。
- `dynamic_cutout_fusion`：真人动态抠像与纸媒、照片和关系图层处于同一空间，允许合理前后遮挡。
- `mixed_by_scene`：不同语义镜头在上述模式间切换，但每次切换必须写明原因和接力方式。

选择模式时先检查原片构图、脸和动作、视觉解释需求与安全区。原片烧录字幕可以自然存在，不得为了隐藏它而破坏人物比例或整体构图。不得把某一种模式写成系列默认，也不得因为原片是竖屏就自动缩成人物卡片。

### 连续性与新信息硬检查

- 每个镜头必须说明它承接上一镜的哪个元素、动作或语义，不能无理由跳切。
- 每个镜头必须引入至少一项新信息、关系变化、观点推进或视觉结论；只有装饰变化而没有信息变化时，必须合并或重新设计。
- 新信息出现的先后必须服从原声/SRT 的语义顺序；不得为了“画面丰富”提前泄露后文结论。
- 预览关键帧审核时逐镜回答：“观众这一镜新看懂了什么？”答不出来就退回执行大纲。

## 视觉丰富度与反单调规则

“简洁”不等于“单一”。进入 Remotion 前，执行大纲必须为每个语义段选择视觉表达方式，并在相邻镜头间主动轮换：纸张/照片拼贴、色块分区、时间线/路径、卡片组装、标签与印章、关系连线、局部放大、遮罩擦过、真人动态窗口、MG 动画、受控的三维或空间层次。需要图像素材时，可使用经过审核的 MJ（Midjourney）拼贴素材；素材只承担视觉解释，不能替代原文事实。

### 图像主导，文字辅助

- 不得把“白底大字 + 一个矩形卡片”作为默认镜头模板，也不得连续用文字卡片代替视觉叙事。
- 每个语义段必须先确定一个真实图像、照片、纸媒物件、关系图形或 MG 构建过程作为视觉主角；文字只负责标题、关键词、字幕和必要标注。
- MJ（Midjourney）生成的是无乱码的图像/拼贴素材，中文文字由 Remotion 精确叠加；不能把生成的文字图当成最终画面。
- 卡片可以作为纸媒物件或关系容器使用，但必须与照片、物件、路径、真人或其他图层建立语义关系，不能单独承担整段内容。

### Vox 组件细节与层级质量

- 允许并鼓励加入贴图、纸张边缘、照片碎片、胶带、标签、印章、手写标记、剪切线、折痕和轻微颗粒，让画面有真实纸媒层次。
- 每个组件必须明确前后关系和遮挡关系；边缘、阴影、纹理、比例、对齐和进入/退出动作要统一，不能只用几个粗大的色块拼出“分层”。
- 大层级之外必须有中小层级：主物件、关系物件、细节标记和微动元素共同组成画面；但视觉中心只能有一个。
- 贴图和装饰必须服务语义或空间关系，不能为了填空白随机增加；相邻镜头的贴图组合、材质和构图要有变化。
- 关键帧审核逐项检查：是否有穿帮式叠压、悬浮无接触、阴影方向不一致、边缘过硬/过脏、组件比例失衡或大面积空洞。

画面应保持“持续有变化”的视觉节奏：背景纹理或纸张可做低幅连续运动，信息和 MG 元素按语义事件频繁接力，旧元素滑走、折叠或被前景擦过时，新元素应立即建立新的视觉关注点。目标是减少无意义的静止和空白，但不是让每个元素、每一帧都高速运动；结论和关键字幕必须保留足够阅读停留，避免晕眩和信息过载。

- 连续两个镜头不得完全复用同一版式、同一主色块和同一进入动作，除非语义明确要求保持连续。
- 每个镜头至少有一个“构建关系”的动作，不能只靠整体缩放、淡入淡出或字幕跳出充当全部动效。
- 多图层、多色块和 MJ 拼贴应优先服务信息层级、对比和记忆点；视觉中心必须唯一，不能所有元素同时抢注意力。
- 相邻镜头要有“变化 + 接力”：画面表达方式改变，但路径、纸张、标签或声音可以把观众带入下一镜。
- 预览关键帧若看起来像静态海报或连续模板，必须回到执行大纲增加层次、关系动作或版式变化后再审核。

## 参考样式的继承边界

用户提供的示例图片或上一条已生成视频，只能作为本次任务的参考，不能自动变成后续任务的固定模板。执行大纲必须写明参考范围：本次复用的是构图、材质、色彩、动效机制，还是仅用于质量对标。

- 用户明确说“沿用这个版式/风格”时，才可在本次任务按指定范围复用，并记录为 `system_anchor` 或对应的参考决定。
- 用户没有明确要求时，默认回到 Vox 自身风格，并主动改变版式、主色块、素材组合、镜头衔接和动效方式。
- 新任务开始时不自动继承上一次任务的参考图、版式或镜头模板；如有歧义，先询问“是否需要沿用上次风格，还是采用新的 Vox 方案”。
- 即使用户要求沿用，也只继承明确批准的范围，不复制整条视频的镜头顺序、素材、文字或动画。

## 声音边界

原始资料审核确定 BGM 情绪、能量曲线和可用音色；本大纲确定具体时间码、口播词、触发动作、音效类型、强度和持续时间；Remotion 只执行已批准的声音计划。BGM 和音效独立可移除，且明显低于人声。

## 交付与审核

先生成 `edit-outline.md`，再按大纲制作视觉方案和实际 Remotion 预览。按语义节点抽取关键帧，关键帧审核通过后才进行完整时间轴渲染。
